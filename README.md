# Редактирование JS source кода
1. Директория source `JS`:  `C:\inetpub\syssupport\wwwroot\js`;
2. При внесении изменений в обязательном порядке создать backup в директории `C:\inetpub\syssupport\backup`.
# Редактирование лимитов пользователя
1. При помощи `RDP` протокола (mRemoteNG) подключиться к серверу;
2. Перейти по директории: `C:\inetpub\SystinSupportAPI\DB;
3. Скопировать файл `SupporHelper.db` с сервера (Желательно к себе в локальную среду);
4. Формат файла `sqlite3`, поэтому необходимо скачать утилиту для чтения [SQL-BD](https://sqlitebrowser.org/dl/) **DB Browser (SQLite)**;
5. Открыть скопированный файл БД нажатием на кнопку _"Открыть существующий файл базы данных"_ — ![[Open_Database.png]];
6. Перейти на вкладку просмотра данных `Browse Data`:![[Browse_Data.png]];
7. Выбрать таблицу `LkOwnerLimit`:
	![[Table_Choose.png]]
8. Таблица должна иметь приблизительно следующий вид:
	![[Columns.png]]
9. Где следующие поля (колонки – `column's`): 
	1. `id` — первичный ключ: `Primary Key`; Его нельзя изменять. Как и любая СУБД или другой инструмент не позволит вам его редактировать.
	2. `ownerId` —  внешний ключ: `Foreign Key`; Значение которого фактически является ID Владельца.
	3. `LkLimit` — обычное поле с числовым значением; Значение данного поля задаётся фактическим параметром лимита у данного владельца.
10. Создать новую запись (Кортеж) при помощи копирования существующего кортежа, можно при помощи кнопки _"Дубликат записи"_ или нажатия хоткея: `Ctrl + "`; (`Ctrl + Shift + 2`):
	 ![[Row_Copy.png|186]]
	 Или создать запись путём нажатия кнопки _"Добавить новую запись в текущую таблицу"_ в верхней части UI: ![[Row_Add.png]];
11. Заполнить колонки соответствующими данными в правой части интерфейса клиента **DB Browser for SQLite**:
	![[Editor.png]]
12. После изменения значений нажать на кнопку `Применить` — ![[Apply_Changes_Button.png]];
13. Сохранить изменения путём нажатия хоткея `Ctrl + S` или нажатием на кнопку _"Записать изменения"_ — ![[Write_Changes_Button.png]];
14. После сохранения можно закрыть **DB Browser for SQLite**.
15. Для внесения изменений необходимо в обязательном порядке создать backup в директории `C:\inetpub\SystinSupportAPI\BACKUP`
16. Далее вносим изменения путём замены файла `C:\inetpub\SystinSupportAPI\DB\SupporHelper.db`
